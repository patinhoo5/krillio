# Krillio

A daily word game for the phone. Seven prompts, twenty-five seconds each: name one thing that fits.
Answers that many players give earn few points; answers few people think of earn many.
Every point takes your krill swarm deeper, and a perfect 700 reaches the Challenger Deep at 10,935 m.

- **Start a descent**: seven fresh prompts, as often as you like.
- **Today's descent**: one set of prompts per day, the same for every player.
- 100 prompts with estimated answer frequencies. Answers outside a prompt's list receive 50 points.
- Plain HTML, CSS and JavaScript. No build step, no tracking, works offline after the first visit.

## Play it on an iPhone

1. Open the GitHub Pages address in **Safari**.
2. Tap **Share**, then **Add to Home Screen**, then **Add**.
3. Open Krillio from its new icon. It runs full screen.
